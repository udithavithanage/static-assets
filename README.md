# Static Assets

A collection of images and static assets for web projects.

## About

This repository contains static resources such as images, icons, logos, and other assets used across different projects.

## Usage

Assets in this repository can be used directly in web projects through their GitHub raw URLs.

```html
<img
  src="https://raw.githubusercontent.com/udithavithanage/static-assets/main/example.png"
  alt="Example"
/>
```
